A program that writes one sharp sentence: a one-star review of Earth by an alien tourist who still admits the food was excellent. The locals worship a burning ball of gas, queue for hours, and stare at glowing rectangles — but the street tacos nearly earned this planet a second star.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
